# Normal ZIP

An archive manager for macOS, focused on reliably editing existing archives.
ZIP, RAR, TAR, TAR.GZ and GZIP — open, extract, add, delete, rename, convert.

**[Download the latest release](https://github.com/normal-soft/normal-zip/releases/latest/download/normal-zip.dmg)**
· [normal-soft.github.io/normal-zip](https://normal-soft.github.io/normal-zip/)

- macOS 13.0 or later, Apple Silicon only.
- Edits never touch the original in place: the new archive is written to a
  temporary file, verified, and only then atomically replaces the old one.
- The build is signed ad-hoc, so macOS asks for confirmation on first launch:
  right-click the app and choose **Open**.

This repository hosts the releases and the website. The source is kept in a
private repository and is not published here.
